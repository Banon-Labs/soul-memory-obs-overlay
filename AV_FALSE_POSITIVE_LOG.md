# Windows AV False Positive Log

Track antivirus false-positive submissions for release artifacts here.

## Submission Portal

- Microsoft Defender submission portal: https://www.microsoft.com/en-us/wdsi/filesubmission
- Submit as: `Software developer`

## What To Record

For each detection event, record:

- Release tag or commit
- Exact asset file name and SHA256
- Detection name/signature from `defender-scan-report.json`
- Microsoft submission ID
- Additional vendor ticket IDs (if any)
- Resolution status/date
